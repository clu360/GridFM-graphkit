# Literature Library Guide

No literature papers are bundled in this package unless separately provided by
Caleb. Add papers to `provided_papers/`, then add one entry per paper to a
versioned literature index.

Recommended workflow:

1. Save the paper or repository citation under `provided_papers/`.
2. Create a note in `literature_notes/` using `LITERATURE_INDEX_TEMPLATE.md`.
3. Tag by topic under `topic_tags/` if useful.
4. Move superseded notes to `archived_or_superseded_notes/`.
5. Do not attribute project methodology to a paper until the source is inspected.
