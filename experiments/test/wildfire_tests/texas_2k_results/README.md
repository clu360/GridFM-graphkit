# Texas2k Results

Texas2k result packages are organized by research stage so later extensions can
reuse the grid without mixing methodologies or artifacts.

## Contents

- `stage_k/`: environmental snapshot, PACE smoke test, validated production
  run, post-run analysis, figures, tables, and the Stage K analysis plan.

Methodology, implementation, configuration, and runbooks remain beside their
stage-specific source code under `../stage_k_case_study/`.
