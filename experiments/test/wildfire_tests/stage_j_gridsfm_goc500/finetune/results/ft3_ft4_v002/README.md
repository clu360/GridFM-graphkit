# Stage J FT3/FT4 FullTop FT n1000 Checkpoint

This is the Git-ready publication of the validated FT3/FT4 working package.

- Tabular working CSV files are published as Parquet.
- Artifact filenames use short deterministic path hashes to stay within Windows path limits.
- `PUBLICATION_MANIFEST.json` maps every published file to its original path and records row counts, sizes, and SHA-256 hashes.
- The authoritative working package remains outside Git at the `source_root` recorded in the manifest.
